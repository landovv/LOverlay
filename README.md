# LOverlay

A modern media overlay for Windows with a glass-like interface, smooth animations, album artwork, and built-in media controls.

> Designed to feel native, lightweight, and always available.

## Features

* ✨ Modern Liquid Glass interface
* 🎵 Displays the currently playing song and artist
* 🖼️ Automatic album artwork
* ⏯️ Play / Pause, Previous, Next controls
* 🔊 Live system volume indicator
* ⚡ Smooth show/hide animations
* 🪶 Lightweight and runs in the background
* 🖥️ Optimized for Windows 10 & Windows 11

---

## Requirements

* Windows 10 or Windows 11
* Python 3.10 or newer
* Node.js 20+
* Microsoft Visual C++ Redistributable (usually already installed)

Install Python dependencies:

```bash
pip install -r requirements.txt
```

Install Node.js dependencies:

```bash
npm install
```

---

## Installation

### Download

Download the latest release from the **Releases** page.

After downloading:

1. Extract the archive.
2. Launch **LOverlay.exe**.
3. If Windows asks for administrator permissions, allow them.
4. The overlay will automatically appear when media starts playing.

---

## Building from Source

Clone the repository:

```bash
git clone https://github.com/landovv/LOverlay.git
cd LOverlay
```

Install dependencies:

```bash
npm install
pip install -r requirements.txt
```

Run the application:

```bash
npm start
```
